# Product

## Register

product

## Users

Chinese-speaking developers, AI client users, and team administrators who need to connect coding agents and applications to a managed AI API gateway without first becoming protocol experts.

## Product Purpose

Zipkiwi gives users one place to create API keys, discover available models, connect supported clients, and verify usage. Success means a new user can move from an account to a confirmed agent request with the correct key, endpoint, model, and protocol.

## Brand Personality

Professional, trustworthy, and clear. The interface should feel technically credible while explaining decisions in ordinary user language.

## Anti-references

Avoid generic SaaS marketing pages, documentation organized around internal implementation details, decorative complexity, unverified compatibility claims, and examples that hard-code stale model availability or pricing.

## Design Principles

- Start from the user's task and name the exact next action.
- Prefer built-in guided configuration before manual file editing.
- Keep protocol differences visible at the moment they matter.
- Make verification part of every setup flow, not an afterthought.
- Treat live model availability, permissions, and pricing as runtime facts.

## Accessibility & Inclusion

Target WCAG 2.1 AA contrast and keyboard navigation. Support narrow mobile screens, visible focus states, reduced motion, readable code samples, and Chinese and English interface copy.
